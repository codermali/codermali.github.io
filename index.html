十年程序员

十年主场在后端。留下来的不是某一门技术,而是把一件事从想法做到上线的习惯 —— 缺什么补什么,前端、部署、浏览器自动化、模型接入,遇到了就自己做。

这两年在认真面对一个问题:当 AI 能写出大部分代码,这十年攒下的到底还值什么。 边想边做,过程都记在博客里。

做出来的东西

Java · Spring Boot · Vue · Playwright · Docker
homelab 自建一套家庭基础设施
